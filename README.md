# Czytnik plików FAT16
Celem projektu jest zbudowanie parsera kontenerów plikowych, zapisanych w formacie FAT16. 
Zestaw funkcji API do realizacji następujących funkcjonalności:
- Otwieranie, czytanie i zamykanie urządzenia blokowego (w formie pliku).
- Otwieranie i zamykanie woluminu FAT16.
- Otwieranie, przeszukiwanie, czytanie oraz zamykanie plików w systemie FAT.
- Otwieranie, czytanie i zamykanie katalogów.
